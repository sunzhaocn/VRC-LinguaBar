# VRC LinguaBar：测试与兼容性

本记录对应 2026-10-14 的修复。自动化在 Windows、CPython 3.12 x64、PyQt5 5.15.11、python-osc 1.10.2 和 pywin32 312 环境执行。

## 已完成的自动化验证

运行：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

当前 18 项测试覆盖：游戏先于程序启动和随后游戏窗口变化的目标发现；Y 完整按键只接管一次；按住 WASD + Shift 时仍接管 Y；检测到菜单或解除鼠标限制时 Y 不传给游戏；原生文本控件仍可输入 Y；系统光标可见和普通 Unity 子窗口焦点不会错误拦截 Y；GUI 线程信息不可用时不会永久禁用 Y；输入条必须拿到真实编辑框焦点；焦点在输入线程附着期间转移到输入条的竞态；输入条允许激活、打开后关闭立即释放会话；Windows 进程快照；当前用户登录项写入与随游戏监视器启动；启动监视器失败时恢复原设置；监视器在同一轮游戏中只启动一次程序。

另执行 `py_compile` 和按仓库 CRLF 行尾设置的 `git diff --check`。现场观察到截图菜单打开时鼠标限制区域为全屏、关闭菜单后的正常移动状态为屏幕中心一点。重复启动第二份程序会立即退出，新实例不会再创建窗口或键盘钩子。以上自动化只证明对应本地代码路径；其他显示模式、反作弊行为和 OSC 接收仍需实测。
