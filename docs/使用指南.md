# VRC LinguaBar 使用指南

本指南对应“直接按 Y、失焦自动关闭、纯文本实时同步”的版本。

## 1. 适合什么场景

你在 VRChat 中需要输入中文、日文或其他依赖系统输入法的语言，但游戏原生输入框的候选显示或组词体验不理想。VRC LinguaBar 把实际编辑放到一个 Windows 桌面输入条中，让原生输入法负责显示候选词，确认后的文字通过 OSC 进入游戏聊天气泡。

它支持的是**已经安装在 Windows 中的输入法**，不是自动翻译工具，也不会下载语言包。当前交互面向桌面键盘输入；它不是 VR 头显内的原生浮层。

## 2. 安装前检查

| 检查项 | 应满足的条件 |
|---|---|
| 系统 | Windows 10 或 11；本次测试环境为 Windows 11 x64 |
| Python | 最低 3.10，建议 CPython 3.13 x64；实际测试 3.13.15 |
| 输入法 | 已在 Windows 添加所需语言，并且能在记事本正常组词、显示候选框 |
| 游戏 | VRChat PC 客户端，OSC 已开启 |
| 旧工具 | 已关闭旧版或重复运行的输入条，避免多个钩子竞争 Y |

依赖版本固定为 PyQt5 5.15.11、python-osc 1.10.2、pywin32 312；精确 Qt 运行环境另固定 PyQt5-Qt5 5.15.2 和 PyQt5-sip 12.19.0。完整说明见 [README](../README.md#环境与依赖版本)。

## 3. 安装和启动

解压项目，在该目录打开终端，执行：

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe .\vrchat_linguabar.py
```

启动后程序主要驻留在后台；输入条不会一直占据屏幕。有系统托盘时可以通过托盘菜单退出。

在 VRChat Action Menu 中打开 **OSC → Enabled**，然后关闭游戏菜单与相机，回到正常游戏画面。默认聊天数据发送到本机 `127.0.0.1:9000`。[官方端口与启用说明](https://docs.vrchat.com/docs/osc-overview)

## 4. 多语言输入与候选框

1. 让 VRChat 位于前台，直接按 **Y**。
2. 输入条打开后，使用你平时切换 Windows 输入法的方式选择语言，例如默认配置下的 Win+Space。具体快捷键取决于 Windows 设置。
3. 输入拼音、假名或其他组词内容；候选列表由该输入法显示。使用输入法自己的数字键、空格、方向键或鼠标完成选词。
4. 确认候选后，文字进入输入条，并实时同步到游戏气泡。
5. 按 **Enter** 发送最终文字并关闭输入条。

**中文示例：**选择微软拼音，输入 `ni hao`，在系统候选框中选出“你好”，再按 Enter 发送。

**日文示例：**选择微软日文输入法并进入所需输入模式，输入假名，使用转换候选确认汉字或词语，再按 Enter 发送。

**英文示例：**选择英文布局，直接输入文字，再按 Enter 发送。

组词时，第一次 Enter 可能只是确认候选，不会立即发送整句。这是为了保留输入法的正常选词行为。程序还对刚完成的 IME 提交使用短暂的防误发送保护；如果候选确认后极快再次按 Enter 没有发送，稍停一下再按即可。

候选框的外观、词库、联想和转换规则由输入法决定。当前实现优先照顾标准 Qt 输入流程及部分微软候选窗；第三方输入法、语言切换面板和不同系统设置可能带来差异，需要实机确认。

## 5. 发送、取消与失焦

| 情况 | 当前行为 |
|---|---|
| 输入条中的普通文字发生变化 | 尝试立即发送纯文本，不等待 Enter，不添加点 |
| 还在输入法组词，尚未确认候选 | 预编辑内容留在本地，不直接广播这一段预编辑字符串 |
| Enter | 发送最终文本和通知标志，关闭打字灯、关闭窗口 |
| Esc | 取消并清理；若输入法先消费该键，则先取消组词，再按一次关闭输入条 |
| 点击其他软件、点击游戏其他位置、Alt+Tab | 取消当前输入、尝试清空气泡并关灯，输入条消失 |
| 停止输入约 2.5 秒 | 只关闭打字灯，不关闭输入条，也不自动追加任何文本 |
| 再次按 Y | 新建一次输入；失焦取消的草稿不会自动恢复 |

“最终发送”与“实时同步”都会进入 VRChat 聊天气泡。`notify=False` 的区别是关闭通知音，而不是对其他玩家隐藏文字。因此，不要把 Enter 前的内容当作只有自己能看见的草稿。接口语义参见 [VRChat Chatbox OSC](https://docs.vrchat.com/docs/osc-as-input-controller)。

## 6. 菜单与相机自动防护

程序每次收到 Y 时检查当前窗口及原生 UI 状态。如果检测到可见的系统交互光标、原生菜单或原生输入控件，会把 Y 留给游戏，不弹出输入条。回到正常状态后，下次按 Y 自动恢复；没有需要手动解除的菜单锁。

相机保护读取本机 `/usercamera/Mode`：已知相机模式非 0 时阻止唤醒，收到 0 时自动恢复。[官方相机接口](https://docs.vrchat.com/docs/vrchat-202533)

需要注意两点：

- 游戏中的菜单可能由 Unity 自行绘制，系统光标也不一定能代表每种 UI。该保护是减少误触发的启发式机制，不是完整读取游戏内部菜单状态。
- 如果相机状态未收到、端口冲突或关闭消息丢失，判断可能不完整或过期。当前未实现可靠的相机状态查询与重发协议。

## 7. 命令行参数

```powershell
.\.venv\Scripts\python.exe .\vrchat_linguabar.py --help
```

| 参数 | 默认值 | 用途 |
|---|---|---|
| `--osc-host` | `127.0.0.1` | 聊天 OSC 目标地址；一般保持本机 |
| `--osc-port` | `9000` | 聊天 OSC 目标端口；范围 1–65535 |
| `--osc-address` | `/chatbox/input` | 聊天接口地址；一般不要修改 |
| `--idle-ms` | `2500` | 停止输入后关闭打字灯的等待毫秒数；范围 1–2147483647 |
| `--camera-listen-port` | `9001` | 本机相机状态接收端口；0 表示关闭相机监听 |
| `--vrchat-pid` | `0` | 0 表示接受经验证的 VRChat 进程；指定正整数可限制某个进程 ID |
| `--verbose` | 未启用 | 输出更详细的运行日志 |

端口修改示例：

```powershell
.\.venv\Scripts\python.exe .\vrchat_linguabar.py --osc-port 9100 --camera-listen-port 9101
```

这个命令只修改工具的端口，**不会替你修改 VRChat 的 OSC 配置，也不会自动配置其他 OSC 程序的转发**。必须确保游戏接收 9100、对应输出或转发发送到本机 9101。

PID 示例：

```powershell
.\.venv\Scripts\python.exe .\vrchat_linguabar.py --vrchat-pid 12345
```

`12345` 仅为示例，应替换成当前 VRChat 进程的实际 PID；游戏重启后 PID 通常会改变。

## 8. 常见问题

| 现象 | 建议检查 |
|---|---|
| 提示找不到 PyQt5、pythonosc 或 win32gui | 确认安装和启动使用的是同一个 `.venv\Scripts\python.exe`；重新安装 `requirements-lock.txt` |
| 按 Y 没有出现输入条 | 确认程序仍在运行、VRChat 位于前台、游戏菜单和相机关闭；检查是否指定了旧 PID，以及是否有其他输入工具在拦截 Y |
| 启动时提示相机 OSC 不可用 | UDP 9001 可能已被其他程序占用。停止冲突的监听器，或配置独立输出/转发端口；仅更改本工具端口不够 |
| 输入条可以打字，但游戏不显示 | 确认 VRChat OSC 已开启；核对目标地址、端口和游戏 Chatbox 显示设置 |
| 能输入拼音或字母，但没有候选框 | 先在记事本测试该输入法；确认当前输入法及中/英文模式正确，且输入条确实有焦点 |
| 点候选框时输入条关闭 | 可能是未识别的第三方独立候选窗口；尝试微软拼音/微软日文，并记录输入法名称、版本与具体动作作为兼容性反馈 |
| Enter 没有立即发送 | 可能正在确认候选，或刚完成组词；确认候选后再按 Enter |
| 还没按 Enter，别人已经看见文字 | 这是当前纯文本实时同步行为，详细解释见第 5 节 |
| 中文候选窗正常，但某个特殊菜单里误触发 | 菜单状态检查不覆盖所有 Unity UI；请记录具体菜单、系统光标是否可见及触发步骤 |
| 失焦关闭后气泡仍短暂存在 | 工具会尝试发送清空包，但 UDP 和游戏客户端行为不提供绝对清除保证 |
| 独占全屏下焦点切换不正常 | 可尝试窗口化或无边框窗口模式验证；不同游戏显示模式尚需实机测试 |

需要报告问题时，可提供 Windows 版本、Python 和依赖版本、输入法名称、游戏显示模式、复现步骤及必要的错误日志。分享日志前请自行检查是否含有个人信息。

## 9. 退出与更新

通过托盘菜单“退出”，或在启动程序的控制台按 Ctrl+C。关闭输入条本身只结束一次聊天，后台工具仍保持运行，等待下次 Y。

更新时先退出旧进程，再替换文件并安装对应版本的依赖。不要同时运行多个副本。项目目前没有自动更新器，也不提供本指南以外的安装服务。
